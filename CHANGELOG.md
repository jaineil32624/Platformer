# Changelog

All notable changes to this project are documented here. Format follows

## [1.0.0] — 2026-10-19

### Added
- Six levels across meadow, forest, cliff, cave and storm themes.
- Player movement: run, sprint, variable jump, double jump, wall slide/jump, one-way drop-through,
  coyote time and jump buffering.
- Enemies: slime, spiky beetle, bat. Bosses: The Slime King and The Storm Golem.
- Health, lives, coins, checkpoints, 5 power-ups, scoring and 3-star ratings with par times.
- 3 save slots with autosave, resume-from-checkpoint and save export/import.
- 14 achievements and per-level local leaderboards (pluggable provider for online boards).
- Procedural art, animations, particles, parallax, dynamic day/night lighting and weather.
- Procedural Web Audio soundtrack (5 tracks) and 23 sound effects with volume controls.
- Keyboard, gamepad and touch controls; responsive, adaptive UI for phones, tablets and desktops.
- Main, settings, pause, level select, save slot, achievements, leaderboard, credits, level complete
  and game over screens with keyboard/gamepad navigation.
- Capacitor (Android/iOS) and Electron (Windows/macOS/Linux) packaging, PWA/offline web build,
  GitHub Actions for CI, Pages deploy and tagged releases.
- Documentation, store listing and privacy policy templates, testing checklist.
